# 清新绿色分割线与紧凑内容选择设计

## 目标

根据两张 Windows 截图，删除待办顶部统计卡片，压缩笔记左侧栏，并将 Windows/Android 及其他 tab 的黑色分割线统一替换为清新的浅绿色，同时保证待办和笔记内容可以用鼠标自由拖选复制。

## 已确认的范围

### 待办顶部

- 删除整块“进行中/已完成”统计卡片及其占位高度。
- 不删除、不迁移待办数据；待办日期选择、添加、编辑、顺延和完成逻辑保持不变。
- 宽屏顶部保留日期条、今天、视图选择和添加待办等必要控件；窄屏/Android 保持现有响应式结构。

### 笔记侧栏

- Windows 宽屏左侧栏由约 320px 压缩到约 160px。
- 顶部新建、分组、回收站按钮改为更紧凑的排列，搜索框和分组列表缩小内边距与字号。
- 窄屏/Android 仍使用单栏列表与详情切换，不强行显示固定宽度侧栏。

### 统一绿色分割线

- 新增主题语义色 `greenDividerColor`，浅色模式使用低饱和浅绿色，深色模式使用可见但不刺眼的深浅绿色。
- `Divider`、`VerticalDivider`、`DividerTheme`、卡片 outline、ExpansionTile 分组线、输入区域 underline 等作为结构线的颜色统一引用该语义色。
- 阴影可以继续使用黑色透明度，但不得用于表达结构分割线；白色调色板圆环等内容性边框不在本次替换范围。

### 鼠标复制

- 待办标题和截止时间使用 `SelectableText`，保留点击编辑和复选框等交互。
- 笔记列表标题/摘要和笔记详情 Markdown 使用可选择文本；详情继续通过共享 Markdown 查看器渲染。
- 不改变数据库字段、云端协议或 Markdown 源文本；复制行为只改变展示层。

## 技术方案

1. 在 `AppTheme` 中定义浅色/深色绿色分割线，并让 `dividerTheme`、`CardTheme` 的结构边框使用该颜色。
2. 在 `TodoPage` 移除 `_TodoHeader` 的渲染调用及相关布局间距，保留统计数据用于其他必要的局部提示（若无消费者则删除组件）。
3. 在 `NotesPage` 的宽屏 `Row` 中将侧栏 `SizedBox` 宽度改为约 160px，并针对侧栏控件设置紧凑 visual density；Android 分支不受影响。
4. 以 `SelectableText` 替换待办和笔记列表中的非编辑文本；文本组件不包裹会拦截鼠标拖选的 `GestureDetector`，右键菜单继续由外层操作入口提供。
5. 增加主题、布局和文本选择回归测试，确保其他 tab 使用同一主题语义色。

## 验收标准

1. Windows 待办截图中的统计卡片整块消失，顶部和列表之间不留空白占位。
2. Windows 笔记左栏宽度约为原来一半，列表仍可搜索、分组、选择、删除和新建。
3. 其他 tab 页面不再出现黑色结构分割线；结构线呈浅绿色且在深浅主题下可读。
4. 鼠标可以拖选并复制待办标题/截止时间、笔记列表摘要和笔记详情正文。
5. `flutter test`、`flutter analyze` 通过，现有同步和数据模型测试不受影响。
