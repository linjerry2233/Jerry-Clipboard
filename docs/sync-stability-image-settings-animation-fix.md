# Windows 同步稳定性、图片同步开关与设置页动画修复

## Windows 同步状态抖动

### 根本原因

1. 定时同步、手动同步和增量同步可能同时操作同一个 Git 工作区，产生索引、锁文件或推送竞争。
2. 增量同步在单条数据写入工作区后立即显示乐观成功，但真正的 commit/push 可能随后失败，导致成功和失败提示互相覆盖。
3. 单条数据加密或解析失败时会立即发送错误状态，但批处理仍继续并在结尾发送成功状态。
4. 短暂的 DNS、连接中断或超时直接暴露为失败，没有进行有限重试。

### 修复

- 新增进程内同步协调器，定时、手动和增量同步按提交顺序串行执行。
- 增量同步不再逐条发布乐观成功，只在整批 commit/push 完成后发布一次最终结果。
- 单条处理错误会累计到本次任务，任务不会再以“部分失败但整体成功”结束。
- Windows Git fetch/push 对可识别的瞬时网络错误最多重试三次；认证失败、分支冲突等确定性错误不会反复重试。
- 远端数据解析失败时不更新 `lastSyncedCommitHash`，下次同步仍会重试该数据。

## 剪贴板图片同步开关

云同步设置中新增“同步剪贴板图片”开关。

- 默认开启，兼容旧版本行为。
- 关闭后不上传新的剪贴板图片。
- 关闭后不下载或覆盖云端图片。
- 云端图片的删除事件不会误删本地图片。
- 文本和链接剪贴板不受影响。
- 配置写入 `cloud_sync.json`，Windows 和 Android 共用。

关闭开关不会删除本地图片。若还需要删除云端已经存在的图片，应在关闭开关后执行一次“同步至云端”，由全量覆盖流程清理不再参与同步的图片文件。

## 设置页动画

- 设置页使用自定义水平路由动画，从屏幕右侧向左滑入。
- 保存、右上角关闭、系统返回时均向右滑出。
- 移除原先由平台路由带来的渐变/弹窗动画。
- 设置页右上角新增关闭按钮，关闭时不保存未提交的设置。
