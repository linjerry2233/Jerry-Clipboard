# 标准时间与 NTP 校时实现报告

## 需求落地

- 新增“标准时间”Tab，使用数字时钟显示到秒，并显示日期、当前 NTP 服务器、上次成功同步时间和立即同步按钮。
- 时间显示固定使用上海时区 `Asia/Shanghai`（UTC+08:00），不读取设备时区，因此 Windows 与 Android 的显示规则一致。
- 设置页新增 NTP 配置卡片：可以选择预设服务器、添加或删除自定义服务器，并设置自动同步频率。
- 自定义服务器支持主机名或 IP，端口可选；未填写端口时使用标准 NTP 端口 `123`。
- 默认服务器为阿里云 NTP，默认同步频率为 30 分钟。频率限制为 5 分钟至 24 小时，避免过高的网络和 CPU 唤醒开销。

## 预设服务器

当前预设包括：

1. `ntp.aliyun.com`
2. `time1.cloud.tencent.com`
3. `ntp.ntsc.ac.cn`
4. `time.edu.cn`
5. `cn.pool.ntp.org`

同步顺序是当前选中服务器、自定义服务器、预设服务器，并自动去重。单台服务器超时或返回格式错误时会继续尝试后续服务器；全部失败时保留上一次有效校时结果，不会把时钟回退成错误时间。

## 技术实现

- 使用纯 Dart `RawDatagramSocket` 发起 NTP UDP 请求，不依赖平台命令或外部进程。
- NTP 数据包严格校验响应长度、协议版本、服务端模式、stratum 和 transmit timestamp。
- 根据请求发送时间、响应接收时间和服务端 transmit timestamp 计算时钟偏移；页面显示“设备 UTC 时间 + 校时偏移 + 8 小时”。
- `NtpNotifier` 负责时钟每秒刷新、自动同步定时器、同步串行化、失败保留和设置持久化。
- 设置保存后会立即重新配置运行中的 NTP 定时器，新的频率无需重启应用即可生效。
- 成功同步时持久化服务器、上次同步时间和偏移量；应用离线启动时仍可显示本地时间或上次校准后的有效时间。

## 使用说明

打开设置 → 外观，在“NTP 服务器”中选择预设地址；如需自定义，输入 `主机名`、`IP` 或 `主机名:端口` 后点击加号。选择同步频率并保存后，应用会按新频率轮询 NTP 服务。标准时间 Tab 中的“立即同步”可随时手动校时。
