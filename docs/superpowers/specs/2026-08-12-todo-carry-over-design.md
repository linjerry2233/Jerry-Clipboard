# 待办顺延到下一天设计（任意日期）

## 目标

Windows 与 Android 的待办页面都支持把当前选中日期中的未完成待办顺延到下一自然日。日期可以是过去、今天或未来；“全部待办”汇总视图不显示顺延按钮，因为该视图没有唯一的来源日期。已完成待办始终不能顺延。

## 行为规则

- 选中日期视图：未完成待办显示紧凑的“顺延到明天”图标。
- 点击后只更新原待办的 `dueDate`，保留 Isar `id`、云端 `syncId`、标题、优先级和提醒等字段。
- 有截止日期时，按日历日期加一天并保留时分秒；无截止日期时使用点击时刻的明天作为截止时间。
- 操作成功后从当前日期列表移除，并通过现有保存链路刷新本地列表、触发增量同步和显示提示。
- “全部待办”视图和已完成待办不显示按钮。
- 保存或同步失败时保留原任务，不产生重复任务。

## 实现边界

领域层继续复用 `TodoNotifier.carryToNextDay` 和 `save`，不新增同步协议、云端文件命名或删除墓碑逻辑。页面层只把“当前是否为全部视图”转换为 `canCarryOver`，因此两个平台共享相同规则。

## 验证

- 日期计算覆盖月末、年末和无截止日期。
- 领域层验证保留本地/云端身份且拒绝已完成任务。
- 页面层验证选中日期视图显示按钮、全部视图隐藏按钮、已完成任务隐藏按钮。
- 运行待办回归测试、`flutter analyze`、Windows Release 构建和 Android Release 构建。
