# 笔记编辑器紧凑布局与单面 Markdown 视觉编辑

## 变更

- 编辑器顶部固定为两行：第一行放标题、分组和保存操作，第二行放紧凑工具栏与自动保存提示。
- 工具栏高度为 32px，减少编辑器头部占用。
- 编辑态默认显示单面、全宽的 `MarkdownDocumentViewer`，输入内容不会再和源码左右对照。
- 需要修改 Markdown 源码时，点击代码图标进入源码模式；点击预览图标返回视觉模式。
- 保留粘贴快捷键、图片插入、自动保存和原有数据模型。

## 验证

- `test/note_editor_layout_test.dart` 覆盖单面视觉编辑、源码模式无分栏和工具栏高度。
- `flutter analyze` 通过。
- `flutter test` 全量通过。
